Audit workflow

  1. Run Lighthouse with the Accessibility category selected.
  2. Save the initial report screenshot before editing the site.
  3. Review the report and identify at least three real failing audits.
  4. Fix the issues, then test keyboard navigation and visible focus.
  5. Run Lighthouse again and save the improved report screenshot.
  6. Post both screenshots and the fix list on the weekly task page.

Required skip link

Add a skip link as the first focusable control on your course project. It should become visible on keyboard focus and target the main content landmark.

<a class="skip-link" href="#main-content">Skip to main content</a>
<main id="main-content" tabindex="-1">

</main>

Capture your initial baseline before adding this or any other fix. Do not enter invented scores or claim a fix without retesting it.
