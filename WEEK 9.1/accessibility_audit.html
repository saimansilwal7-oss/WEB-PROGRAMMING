Week 9.1: Accessibility Audit

Use Lighthouse to inspect accessibility, fix at least three real issues from the report, and document the before-and-after results.

Assignment requirements

  1. Open your personal website and/or team project in Chrome.
  2. Open Developer Tools → Lighthouse. Select only the Accessibility category and run the audit.
  3. Save a screenshot of the initial Accessibility score and report.
  4. Choose at least three failing audits from that actual report and fix them.
  5. Run Lighthouse again using the same settings and save the improved result.
  6. Post both screenshots and a list of the three fixes to the weekly task page.

Sites to audit

  • Personal website
  • Team 4 project

Required: Add a skip link

A skip link lets keyboard users bypass repeated navigation and jump to the main content. Add this near the beginning of the body:

<a class="skip-link" href="#main-content">Skip to main content</a>
<main id="main-content" tabindex="-1">
  ...
</main>

Style it so it becomes visible on keyboard focus. See the working skip-link demo.

Submission checklist

Important: Do not make up scores or audit findings. Enter the values and issues shown by your own Lighthouse reports. The goal is to improve the score, ideally to 100.

Use the audit report template to record your real findings and results.
