Image Alternative Text

Week 9.1 · Practice meaningful alt text for informational, decorative, and functional images.

1. Informational image

The alt text describes the important information in the image.

Alt text: “Illustration of a university campus building with hills in the background.”

2. Decorative image

The decorative wave adds visual style but carries no information, so it uses an empty alt attribute.

Alt text: Empty (alt="") because the image is decorative.

3. Functional image inside a link

The alt text describes the link's destination or action, not just how the image looks.

4. Data image
