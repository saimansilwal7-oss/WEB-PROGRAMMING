# Week 6.1 — Random Joke Fetcher

A responsive Web Programming exercise using the Fetch API, async/await, error handling, a loading spinner, and localStorage.

## Files
- `index.html` — page structure
- `style.css` — responsive styling and loading spinner animation
- `script.js` — API request, error handling, and favourite-joke storage

## Run it
Open `index.html` in a browser with an internet connection. Click **Get a Joke** to request a random joke from the Official Joke API. Use **Save Favourite** to store jokes in the browser's localStorage.

API: https://official-joke-api.appspot.com/random_joke

Note: Favourites are saved in the current browser on the current device.
